# 4. 継続だけの中間表現

## 関数と継続だけ

コンパイラの中心になる中間表現（[src/ir.ml](../src/ir.ml)）には、分岐の合流もループもありません。あるのは関数と「継続」だけです。継続は引数を持つラベルで、制御の流れはすべて「継続へ引数を渡して飛ぶ」で表します。

`sum` 関数は次のようになります（`hlc --ir` で見られます）。

```text
fn sum(p.1: u16, n.2: u8) -> u8 =
  loop.3(0, n.2, p.1)
  cont loop.3(acc.5: u8, n.6: u8, p.7: u16) =
    if n.6 != 0 then
      let t.11: u8 = mem[p.7]
      let t.12: u8 = acc.5 + t.11
      let t.13: u16 = p.7 + 1
      let t.14: u8 = n.6 - 1
      loop.3(t.12, t.14, t.13)
    else
      done.4(acc.5, n.6, p.7)
  cont done.4(acc.8: u8, n.9: u8, p.10: u16) =
    ret(acc.8)
```

- 変数は一度しか束縛されません。`acc += ...` のように値が変わる変数は、継続の引数になります。
- ループは、自分自身へ飛ぶ継続です。
- `break` は `done` へ、`continue` は `loop` へ飛ぶだけです。

この形の良いところは 3 つあります。

- **どこで何が生きているかが明確**：継続の引数が、その地点で受け渡される値のすべてです。
- **レジスタの約束を書ける**：継続ごとに「どの引数がどのレジスタに入って来るか」を決められます。次の章の中心です。
- **中断と再開に延ばせる**：`wait` は「続きの継続を保存して戻る」と表せます（今後の段階）。

## 変換のしかた

[src/cps.ml](../src/cps.ml) の変換関数は、「この先の続きを作る関数」`k` を受け取ります。

```ocaml
(* 式: 値を k に渡す *)
let rec exp env e (k : atom -> term) : term = ...

(* 文: 変数の対応表を k に渡す *)
and stmt lp env s (k : env -> term) : term = ...
```

`env` は「ソースの変数 → いまの値」の対応表です。代入 `x = e` は、対応表の `x` を書き換えるだけで、命令は出しません。

合流点では、対応表が食い違うかもしれない変数を継続の引数にします。`if` なら、どちらかの枝で代入される変数が引数です。

```ocaml
| If (c, t, f) ->
  let vars, ps, enter = merge env (t @ f) in     (* 代入される変数と、その分の引数 *)
  let j = fresh "join" and ps = ps () in
  let go ss () = block lp env ss (fun env -> Jump (j, pass env vars)) in
  LetK ([ { k = j; ps; body = k (enter ps) } ], branch env c (go t) (go f))
```

### 条件は値にしない

`if a < b && c != 0` の条件は、0/1 の値を作らずに、直接分岐にします（`cond`）。`&&` は「左が成り立ったら右を調べる」、`||` は「左が成り立たなかったら右を調べる」という飛び先のつなぎ替えになります。真偽を変数に入れるときだけ、値にします。

## 生存解析

[src/live.ml](../src/live.ml) は、中間表現の各地点に「ここから先で使われる変数」の集合を付けます。コード生成が「このレジスタはもう空いているか」を判断するのに使います。

継続の中からは外側の変数も使えます。だから、継続へ飛ぶ地点では「その継続が外から持ち込む変数」も生きています。継続どうしは呼び合うので、集合が変わらなくなるまで計算を繰り返します。

## 中間表現の上での小さな最適化

[src/opt.ml](../src/opt.ml) は、コード生成の前に中間表現を 1 回なめます。変数は一度しか束縛されないので、どちらも式を見比べるだけで済みます。

- **同じ計算を 2 回しない**：同じ式や同じ番地の読みは、先に計算した変数で置き換えます。`mem[p]` を条件と本体の両方に書いても、読むのは 1 回です。メモリの読みは、間に書き込みや関数呼び出しがあれば読み直します。
- **定数だけの計算は済ませる**：`1 * 5` や、ラベルの番地 + 定数をまとめます。中間表現の値には「ラベルの番地 + 定数」という形があり、`boss.y = 20` は `boss+1` 番地への書き込み、`es[2]` は `es+10` という 1 つの定数になります。

```asm
    ld a,0x14
    ld (boss+1),a                ; boss.y = 20
    ld hl,es+0xa                 ; es[2]（要素は 5 バイト）
    call sum
```

`-O0` ではこの段を通しません。
